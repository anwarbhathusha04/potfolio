## Technical Overview

- **Core Aesthetics**: Minimalist obsidian dark theme inspired by Linear & Vercel design systems.
- **Performance**: Zero external JavaScript frameworks, pure Vanilla JS + CSS3 for instant load times (<100ms).
- **Typography**: Plus Jakarta Sans & JetBrains Mono.
- **Interactivity**: 
  - Dynamic cursor spotlight illumination on feature cards.
  - Interactive project case-study modal dialogs.
  - One-click contact copy with instant toast notifications.
  - Live Chennai, India (IST) timezone synchronizer.
  - Direct PDF resume download integration.

## Local Development

Start the local development server:

```bash
npm start
# Server running at http://localhost:3000
```

---

## Deployment to Vercel

1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework Preset: **Other** / **Static Site** (Root directory: `./`).
3. Click **Deploy**. Vercel will automatically read `vercel.json` and serve `index.html`.
